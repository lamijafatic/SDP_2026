Python Package Manager

Vertex

Dependency resolution modeled as a hypergraph. Fast, conflict aware, no exponential backtracking.

Get Started

Vertex is a command line package manager for Python. It resolves dependencies, locks versions, manages a virtual environment, and checks for updates. It has 23 commands covering project setup, dependency management, resolution, environment installs, and registry search. At its core is a hypergraph based resolution algorithm: packages and versions become nodes, constraints become hyperedges, and versions sharing the same constraints are grouped into role classes before a SAT solver picks a valid assignment. This avoids the exponential blowup that plain backtracking runs into on conflicting dependencies, so resolution stays fast even on large, tangled dependency trees.

Installation

Get Vertex running

Requires Python 3.9+. Only two runtime dependencies: python-sat and toml.

1

Ensure Python 3.9+ is installed

Run python --version to check. If Python is not installed, download it from python.org.

2

Install Vertex via pip

pip install git+https://github.com/lamijafatic/SDP_2026.git
3

Verify the installation

vertex --help
1

Download Python for Windows

Go to python.org/downloads and download the latest Python 3.x installer. During installation, check Add Python to PATH.

2

Open Command Prompt or PowerShell

Press Win + R, type cmd, press Enter.

3

Install Vertex

pip install git+https://github.com/lamijafatic/SDP_2026.git
⚠ If pip is not found, try python -m pip install git+https://github.com/lamijafatic/SDP_2026.git
1

Install Python via Homebrew (recommended)

brew install python

Or download from python.org if you prefer not to use Homebrew.

2

Install Vertex

pip3 install git+https://github.com/lamijafatic/SDP_2026.git
3

Verify

vertex --help
1

Clone the repository

git clone https://github.com/lamijafatic/SDP_2026.git
cd SDP_2026
2

Install in editable mode

pip install -e .

Editable mode means changes to the source are reflected immediately without reinstalling.

3

Run the test suite

python test_hypergraph.py
